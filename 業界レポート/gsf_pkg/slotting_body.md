# 第1章　スロッティング・フィーとは何か

## 一言でいうと

**アメリカのスーパーに新商品を置いてもらうために、メーカーが小売店に払う「場所代」。**

元記事の定義はこうです。

> スロッティング・フィーとは、新しいSKU（商品）を置くために小売店が課す料金である。**販売実績のない商品に、限られた棚のスペースを与えることへの対価**である。

## なぜお金を取るのか — 小売店側の言い分

スーパーの棚は有限です。そこに実績ゼロの新商品を置くということは、小売店から見ると次のコストとリスクを負うことになります。

| 小売店が負担するもの | 内容 |
| --- | --- |
| 倉庫のセットアップ | 新商品を保管する場所と作業の準備 |
| システム登録 | 商品コード・価格・発注情報をシステムに入れる |
| 棚割り（プラノグラム）の変更 | 棚のレイアウト図を作り直す |
| **機会費用** | **今売れている商品をどかすことになる** |

いちばん重いのが最後の「機会費用」です。すでに毎週確実に売れている商品を棚から外して、売れるかどうか分からない新商品を置く——その損失リスクを、メーカーに前払いさせているわけです。

## たとえるなら

コンビニのレジ横に自分の商品を置いてもらう権利を、オークションで買うようなものです。場所そのものに価値があるので、場所代が発生する。

# 第2章　まず覚える専門用語

このテーマは用語を知らないと数字の意味が分かりません。最低限これだけ。

| 用語 | 読み方 | 意味 |
| --- | --- | --- |
| **SKU** | エスケーユー | 商品の最小管理単位。「味噌ラーメンキット 13.5oz」で1SKU。味が3種類なら3SKU |
| **Slotting Fee** | スロッティング・フィー | 棚代。**新規で棚に入るための入場料** |
| **Free Fill** | フリーフィル | **初回在庫の無償提供**。「最初の1回分はタダで納品して」という要求 |
| **Pay to Stay** | ペイ・トゥ・ステイ | **棚に居続けるための追加料金**。入場料とは別に、毎年かかることがある |
| **Trade Spend** | トレードスペンド | 値引き・チラシ掲載・販促にかかる費用の総称。**これが一番大きい** |
| **Authorization** | オーソライゼーション | チェーン本部からの「置いてよい」という**承認**。実際に置かれることとは別（→第6章） |
| **Distribution / Door Count** | ディストリビューション／ドアカウント | **実際に商品が並んだ店舗数** |
| **Gross Profit per Case** | グロスプロフィット・パー・ケース | **1ケース（1箱）売って手元に残る粗利** |
| **Velocity** | ベロシティ | 回転率。「1店舗が1週間に何ケース売るか」 |

## 3-2. なぜ冷凍・冷蔵は高いのか

元記事の説明：

> 冷たい棚のスペースは、より希少で、運用コストが高く、リセットが難しい。だから小売店はそこにプレミアムを乗せる。

理由を分解するとこうなります。

1. **冷凍・冷蔵ケースの数は物理的に限られている**（常温の棚のように増設できない）
2. **電気代・メンテナンス費がかかり続ける**
3. **棚割りの入れ替えが常温より手間**

その結果、大規模チェーンの冷凍1SKUで **$20,000〜$100,000** という、常温とは桁の違う数字になります。

# 第4章　いちばん大事な話 — 棚代は「入場料」にすぎない

初めて棚に商品を出す人が最も間違えるのがここです。

## 4-1. 棚代の他にかかるもの

| 費目 | 内容 |
| --- | --- |
| **フリーフィル**（初回無償納品） | 最初に棚を埋める在庫をタダで出す |
| **ペイ・トゥ・ステイ**（居座り料） | 棚に残り続けるための追加料金 |
| **トレードスペンド**（販促費） | 値引き・チラシ・エンド陳列・クーポン。**1年で見ると棚代よりはるかに大きくなるのが普通** |

## 4-2. 元記事が挙げている実例

> この規模で何度も見るパターンは、**棚代に $40,000 を見込んでいた創業者が、そのSKUを棚に定着させるまでに $110,000 近くを使っていた**、というものだ。

**予算の2.75倍**。棚代だけを見て予算を組むと、こうなります。

## 4-3. 会計上の落とし穴

元記事が指摘するもう一つの罠：

> スロッティング・フィーは一般に、**売上原価（COGS）ではなく、売上からの控除**として扱われる。トレードスペンドと同じ扱いだ。その結果、**棚代は純売上の行に効いてくる。だから粗利率は健全に見えているのに、ローンチ全体では赤字**という状態が起こる。

**ここが初心者に一番伝わりにくいところです。** 分かりやすく言うと——

- 棚代は「原価」に入らないので、**粗利率の計算には出てこない**
- 「粗利率40%、いい商品だ」と思っていても、売上から引かれる棚代・販促費のせいで、**実際は赤字**ということが起きる
- だから「粗利率」ではなく「**そのチャネル全体の損益**」で見る必要がある

# 第5章　損益分岐点の計算のしかた

元記事の中核部分です。ここだけは自分で計算できるようになると強い。

## 5-1. 公式

> **損益分岐ケース数 ＝（棚代 ＋ フリーフィル ＋ 居座り料 ＋ その他ローンチ費用）÷ 1ケースあたりの粗利**

日本語にすると：**「かけた初期費用を、1ケースあたりの儲けで割る」**。それだけです。

## 5-2. 計算例（元記事の表）

**棚代 $9,182 の場合**

| 1ケースの粗利 | 損益分岐ケース数 |
| --- | --- |
| $5 | **1,836ケース** |
| $10 | **918ケース** |
| $20 | **459ケース** |

**棚代 $25,000 の場合**

| 1ケースの粗利 | 損益分岐ケース数 |
| --- | --- |
| $10 | **2,500ケース** |
| $20 | **1,250ケース** |

**読み取れること**：1ケースの粗利が2倍になれば、必要な販売数は半分になる。**価格設計が損益分岐に直結する**ということです。

## 5-3. いちばん重要な変換 — 「1店舗が1週間に何ケース売ればいいか」

ケース数のままではピンときません。元記事はこれを**現場の感覚に翻訳**します。

**例**：100店舗、26週間（＝約半年の棚卸しサイクル）で、918ケースを売る必要がある場合

> 918ケース ÷ 100店舗 ÷ 26週間 ＝ **0.35ケース／店／週**

> 1店舗あたり週0.35ケース。これは棚代を回収するだけの数字で、1ドルの利益も出ていない。

## 5-4. なぜこの変換が効くのか

「918ケース」だと多いのか少ないのか分かりませんが、「**1店舗が週に0.35ケース**」なら、営業担当者もバイヤーも**実感で判断できます**。

- 「週0.35ケースなら余裕」→ ゴーサイン
- 「うちの類似商品でも週0.2ケースがやっと」→ **この棚代は払ってはいけない**

**新しいチャネルに出る前に、必ずこの1行に落とすこと。** これが元記事の最大の実務的メッセージです。

# 第6章　最大の落とし穴 — 「承認された店舗数」≠「実際に置かれた店舗数」

## 6-1. 元記事の警告

> **承認は配荷ではない。** ブローカーの報告では、あるブランドが1,000店舗のチェーン承認に $30,000 を払い、**実際に商品が並んだのは120店舗だった**。承認された店舗数を前提に予算を組んでいたら、1店舗あたりの計算は完全に崩壊する。

## 6-2. 何が起きているのか

アメリカの大手チェーンでは、多くの場合こういう二段構えになっています。

1. **本部が「置いてよい」と承認する**（Authorization）
2. **実際に発注するかは、各店舗や地域の判断**（Distribution）

つまり本部の承認は「**置く権利**」であって「**置く保証**」ではない。

## 6-3. 数字で見る破壊力

同じ $30,000 でも：

| 前提 | 1店舗あたりの棚代 |
| --- | --- |
| 1,000店に置かれると想定 | **$30／店** |
| 実際は120店だった | **$250／店** |

**8.3倍**。これで採算計画は完全に壊れます。

## 6-4. 対策

元記事の指示は明快です。

> **承認店舗数ではなく、実際に配荷が見込める店舗数で予算を組むこと。**

契約交渉でも、社内の採算計算でも、必ず**実配荷ベース**で。

# 第7章　棚代を取らない小売もある

## 7-1. 前払いの現金スロッティングを課さない小売

元記事が挙げているのは以下の4社です。

- **Walmart**
- **Costco**
- **BJ's Wholesale**
- **Whole Foods**

## 7-2. ただしタダではない

「棚代を取らない」＝「安く済む」ではありません。**別の形で回収します。**

| 小売 | 回収のしかた |
| --- | --- |
| **Walmart** | **最も安い正味卸価格（net-net）を要求する**。つまり価格そのもので取る |
| **ナチュラル系チャネル**（Whole Foods等） | **フリーフィル（初回無償納品）と販促アローワンス**に依存 |

## 7-3. これを使った順番の戦略

元記事が提案する実務テクニック：

> 資金が厳しいなら、棚代のかからないバナーから先に入り、そこで回転率のデータを作る。そのデータを、棚代を取るチェーンとの交渉での強い手札にする。

これは非常に実践的です。順序としては：

1. 棚代ゼロの小売に入る
2. 「週◯ケース売れています」という実績データを作る
3. そのデータを持って、棚代を取るチェーンと交渉する
4. 実績があるので、棚代を値切れる／リスクが低いと判断される

**実績ゼロだから棚代を取られる。だから実績を先に作る。** 理にかなっています。

# 第8章　棚代は交渉できる

元記事のFAQより：

> **Q: スロッティング・フィーは交渉可能か？** A: しばしば可能である。ブランドは、フリーフィル、より深い導入時プロモーション、マーケティング支援、あるいは全国展開前の地域パイロットを提示することで、棚代を引き下げている。

## 交渉で差し出せるカード

| カード | 内容 | 小売側のメリット |
| --- | --- | --- |
| **フリーフィル** | 初回在庫を無償提供 | 小売は在庫リスクゼロで始められる |
| **導入時の深い値引き** | 立ち上げ期の特価 | 客を呼べる |
| **マーケティング支援** | 広告・試食・SNS送客 | 小売が自分で販促しなくていい |
| **地域パイロット** | いきなり全国ではなく数十店で試す | **小売のリスクが小さい**（これが一番効く） |

**発想の転換**：棚代は「請求されるもの」ではなく、「**小売のリスクを下げれば減らせるもの**」。小売が怖がっているのは「売れなかったらどうしよう」なので、その恐怖を減らす提案をすれば、金額は動きます。

# 第9章　卸売 vs 自社EC（DTC）の収益性

元記事が最後に触れている、意外に重要な視点です。

> 良いグロサリー・プログラムなら、トレードスペンドを引いた後でも**30〜40%は確保できる**。卸売では**30%を下限**として考える。

そして著者の核心的な指摘：

> **DTCの限界利益率が約35%だとしても、そこから毎回の注文につき $200 以上の顧客獲得コストを賄わなければならない。一方、卸売の限界利益率30%には、注文ごとの顧客獲得コストが一切かからない。だから顧客獲得コストを差し引くと、卸売が勝つことが多い。**

## 分かりやすく言うと

|  | DTC（自社EC） | 卸売（小売の棚） |
| --- | --- | --- |
| 限界利益率 | 約35% | 約30% |
| 1注文あたりの広告費 | **$200以上** | **$0** |
| **実質** | 広告費を引くと薄い | **お客はスーパーが連れてくる** |

**率だけ見るとDTCが有利に見えるが、集客コストを入れると卸売が勝つことが多い。** 棚代が高く見えても、それは「顧客獲得コストの前払い」だと考えると評価が変わります。

# 第10章　実行チェックリスト（元記事の7項目）

棚に商品を出す前に、この順で確認する。

**① 料金体系を書面で取る**（モデルを作る前に）
→ 「1店舗あたり」か「1商品あたり」か「1チェーン承認あたり」かで、**予算が桁で変わる**

**② 導入コストの総額を出す**
→ 棚代＋フリーフィル＋居座り料＋**初年度のトレードスペンド**まで含める

**③ 1ケースあたりの粗利を、実際の卸価格で計算する**
→ **DTC価格で計算しない**（卸価格はずっと安い）

**④ 実配荷が見込める店舗数で予算を組む**
→ 承認店舗数ではない（第6章）

**⑤ 損益分岐ケース数を出し、「1店舗・1週あたり」に変換する**
→ そして**保守的な回転率予測と比べる**（第5章）

**⑥ 交渉するか、順番を工夫する**
→ フリーフィル・地域パイロット・マーケ支援を差し出す／棚代ゼロの小売から始める

**⑦ 棚代を「売上からの控除」として記録する**
→ チャネル別の損益計算書で管理し、**本当の収益貢献を見る**（第4章）

3. **承認店舗数ではなく実配荷店舗数で予算を組む**
